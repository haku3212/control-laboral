# Supabase Setup

1. Crear proyecto Supabase Free.
2. Instalar Supabase CLI.
3. Ejecutar `supabase login`.
4. Vincular con `supabase link --project-ref TU_PROJECT_REF`.
5. Aplicar migraciones con `supabase db push`.
6. Cargar tipos iniciales con `supabase db seed`.
7. Crear el usuario administrador en Auth.
8. Insertar su perfil como `admin` en `public.profiles`.

No guardar secretos reales en el repositorio.
